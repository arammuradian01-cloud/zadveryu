# «За дверью» — публичный прототип лендинга

Лендинг сервиса планового выноса бытового мусора для жителей жилых комплексов.

## Что работает

- адаптивный лендинг;
- тарифные карточки;
- правила приёма пакетов;
- FAQ;
- интерактивная форма заявки;
- обязательное согласие на обработку персональных данных;
- cookie-уведомление;
- автоматическая отправка заявки в Яндекс 360 при размещении на REG.RU;
- безопасная проверка анкеты без отправки данных на GitHub Pages.

## Важно

Сайт не принимает оплату. Серверный обработчик `submit.php` не содержит паролей и не хранит заявки в файлах или базе: он направляет заявку и доказательство согласия в корпоративный ящик `I@arammuradyan.ru` в Яндекс 360. До реального сбора необходимо подать уведомление в Роскомнадзор и включить MFA в Яндекс 360 и REG.RU.

По умолчанию автоматическая форма выключена. После выполнения обязательных шагов она включается созданием пустого файла `private/form-live.flag` на REG.RU. Пока файла нет, кнопка отправки на основном домене остаётся заблокированной.

## Публикация

Для боевого запуска требуется хостинг REG.RU с поддержкой PHP и HTTPS. На GitHub Pages работает только тестовый режим без серверной отправки. Точка входа — `index.html`.
