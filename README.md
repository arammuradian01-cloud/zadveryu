# «За дверью» — публичный прототип лендинга

Интерактивный статический прототип сервиса планового выноса бытового мусора для жителей ЖК «Вестердам».

## Что работает

- адаптивный лендинг;
- тарифные карточки;
- правила приёма пакетов;
- FAQ;
- интерактивная форма резерва;
- демонстрационный сценарий перехода к СБП.

## Важно

Прототип не принимает оплату, не отправляет и не сохраняет персональные данные. Реальная интеграция СБП, чеков и возвратов будет подключена после регистрации продавца, выбора банка и онлайн-кассы.

## Публикация

Сайт рассчитан на GitHub Pages и не требует сборки. Точка входа — `index.html`.
