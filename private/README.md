# Активация формы

До направления уведомления Роскомнадзору форма должна оставаться выключенной.

После выполнения обязательных шагов создайте через файловый менеджер REG.RU пустой файл:

`private/form-live.flag`

Клиентский код проверяет наличие файла через `submit.php?status=1`. Содержимое файла не читается и не публикуется. Каталог `private` закрыт от прямого веб-доступа файлом `.htaccess`.
